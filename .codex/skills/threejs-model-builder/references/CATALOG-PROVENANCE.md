# Catalog schema, identity, provenance and licensing

## Canonical data model

Read `catalog/models.json` before changes. Each asset contains at minimum `id`, `slug`, `title`, `category`, `tags`, `kind`, `license`, `author`, `dimensions_m` (width/height/depth). Procedural assets additionally require `source_path` and `generator`. Imported `glb`/`gltf` require `binary_path`, `content_sha256`, `file_size_bytes`, `triangle_count` and `vertex_count`. Other supported metadata includes `title_zh`, `summary`, `style`, `accent`, `source_url`, `license_evidence_url`, `provenance_note`, `qa_warnings` and `collection`.

Exact machine contract: repository `schemas/manifest.schema.json` + `scripts/catalog.py`. The JSON schema is an interface description, but the Python validator is also authoritative for consistency rules. To add an optional field to the schema, update both validator and downstream storage projection deliberately.

```bash
python3 scripts/catalog.py validate
python3 scripts/catalog.py build
python3 scripts/catalog.py stats
python3 scripts/export_static_catalog.py
```

SQLite `data/catalog.sqlite` and `catalog/public_models.json` are **projections**, not hand-authored catalog masters. Public projection is bounded (currently 200 assets) for static Pages; large query flows use SQLite / API.

## Provenance decision

**Original procedural model:** author is actual contributor or project owner, with original code under repository licensing terms. Document source/art inspiration if directly based on external references and check whether it is derivative.

**Third-party mesh:** record actual author, source page, precise asset license, evidence URL, acquisition date and modifications, source SHA-256, rights scope and attribution requirements. Verify that the license permits the intended redistribution, commercial use, adaptations and sublicensing where necessary. "Free download", a search snippet, or a repository license on *other code* is insufficient. Stop if rights are ambiguous.

SPDX expressions and license IDs should be checked against [SPDX License List](https://spdx.org/licenses/). Current importer accepts only a basic SPDX-token pattern, so complex SPDX expressions may not be supported; do not silently substitute a permissive ID. Imported GLBs with a different license remain separately licensed even though repository source code is MIT.

## Metadata quality gate

- No duplicate `id` or `slug`; immutable IDs after publication.
- Category exists in `catalog/categories.json`.
- Tags are concise, meaningful and machine-searchable.
- Dimensions are positive, finite, physically plausible and visually checked.
- For procedural: path exists under `src/models/` and exports the declared symbol; generator returns `THREE.Group`.
- For binaries: hash corresponds to the *actual* file, and all structural metrics are generated by audit, not typed from an estimate.
- If `source_url` or `license_evidence_url` does not resolve or show actual reuse rights, flag it for human review.

## Audit trail

Every contribution should ship a brief, QA report, exact file list, catalog diff, baseline catalog count, result count and references to rights evidence. For modifications, preserve old IDs and identify whether saved consumer scenes can safely update. Do not equate passing parser tests with passing legal review.
