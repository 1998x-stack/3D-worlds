# market-intelligence: detailed operator reference

Evidence classes: listing, discussion, official seller guidance and first-hand test are distinct; no ranking is statistically meaningful without sampling. Store exact links and date; availability/prices fluctuate. Amazon Seller University's 3D printing ideas, public eBay listings and Hacker News forums are inspiration, not rights to reuse. Prioritize adaptable holders, useful personalization, repairability and modularity. Ban copied trademarks, characters, protected product silhouettes, patented mechanisms without review, and unsupported food/electrical/medical claims. Score from 0–5 each: problem specificity, visual uniqueness, geometry editability, documentation potential, print risk (inverted). For every selected SKU define hero silhouette, named components, physical dimensions, differentiator, market channel, licensing evidence and unverified assertions. A good batch spans all active categories instead of 30 near-duplicate desk bins.

## Review outcomes

- **Pass** requires actual validation for the declared scope, source links where applicable, and stable names/units.
- **Needs review** means input/scene source exists but no real mechanical/physical/browser evidence.
- **Block** means mismatched source claims, missing provenance, unknown licenses for imported files, invalid dimensions, or unsupported physical safety claims.

## Integration points

Root `AGENTS.md` defines precedence; `catalog/models.json` defines identities and `catalog/collections/` defines release membership. Prefer existing `scripts/` and `tests/` implementations over duplicated logic. Document exceptions and maintain cross-agent reproducibility.
