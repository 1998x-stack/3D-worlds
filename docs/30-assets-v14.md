# V1.4 · 30 original maker-market 3D asset designs

> **Scope:** 30 original, independently editable Three.js recipe models covering the 13 original scene categories (the separate print-commerce category is preserved); 825 named mesh parts. Original concept art geometry, **not** source meshes from stores or Hacker News.

## Research principles

Amazon and eBay provide qualitative evidence that related product concepts are listed or being promoted, not verified sales velocity or profitability. Hacker News informs programmatic geometry, parametric experimentation and maker customization. No listing, trademark, patented mechanism or third-party mesh is copied. Product performance, printability and commercial permissions for a user-created derivative must be evaluated independently.

## Catalog integration

These 30 designs append to 535 existing models for **565 total across 14 categories**, including 50 earlier CAD-backed print-commerce products. The 30 new assets are scene-style Three.js recipes across the original 13 categories, not certified engineering-grade CAD.

## Build and verification

```bash
python3 scripts/catalog.py validate
python3 scripts/catalog.py build
python3 -m unittest discover -s tests -v
npm install
node scripts/validate_models.mjs
npm run generate:assets
npm run verify:assets
npm run build
npm run test:gallery
```

Generated WebP/AVIF images and GLB LODs are CI outputs, not source binaries committed in this PR. Gallery quick STL is a draft only; the print audit's geometry pass is not proof of wall thickness, tolerance, physical strength, or material suitability. Thin geometry (particularly the textile Truchet tile, trellis, mesh and cuffs) must be CAD-redesigned or manually audited before sale or physical printing. The CAD-oriented ideas are represented as visual Three.js blockouts, **not** exact engineering CAD or certified ready-to-print STLs.
