# V1.0｜下一批 50 个原创 3D 资产（335 → 385）

## 本批边界

新增 **50 个可编辑、独立的 Three.js 程序化模型**，总库 **385 个、13 类**，新增 **1,232 个具名几何部件**。全部采用项目原创建模逻辑，不引入未授权第三方模型。每项附中英双语名称、可寻址 ID、源码文件、零件数、米制包围尺寸、MIT 许可证。

这些资产面向网页和游戏场景复用；人物均未绑定骨骼，也不代表工业制造级 CAD、无缝 PBR 材质或可直接 3D 打印的水密模型。

## 使用与 CI 验收

```bash
python3 scripts/catalog.py validate
python3 scripts/catalog.py build
python3 -m unittest discover -s tests -v
npm ci
node scripts/validate_models.mjs
npm run generate:assets
npm run verify:assets
python scripts/smoke_p2.py
npm run build
npm run test:gallery
npm run test:remote
```

预期全量生成：**385 WebP + 385 AVIF + 1,155 个优化 GLB（每资产三级 LOD）**，以及可检索 SQLite、MCP 和 GitHub Pages 静态目录。生成、压缩、浏览器 smoke 和 Pages 部署需以 GitHub Actions 实际结论为准；以上数字不是已经生成的声明。
