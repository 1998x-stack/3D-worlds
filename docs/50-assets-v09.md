# 3D Worlds V0.9｜下一批 50 个原创 Three.js 资产

## 交付边界

在 V0.8 既有 285 个稳定模型上，新增 **50 个独立、可编辑的程序化几何资产**，累计 **335 个**，覆盖原有全部 **13 个类别**。本批共 **1,068 个不同名称的 Mesh 部件**，每个模型含双语名称、MIT 来源、实际几何配方、米制外包围尺寸、独立 JS 文件及可供图形流水线输出的 WebP/AVIF 与 Meshopt GLB 路径。它们是风格化场景资产而非高精度工业 CAD 或 Rigged 人物动画。

## 运行、校验与发布

```bash
python3 scripts/catalog.py validate
python3 -m unittest discover -s tests -v
npm ci
node scripts/validate_models.mjs
npm run generate:assets
npm run verify:assets
python scripts/smoke_p2.py
npm run build
npm run test:gallery
```

流水线预计生成 **335 张 WebP + 335 张 AVIF + 1,005 个 LOD0/LOD1/LOD2 GLB**，具体是否生成及 Pages 是否部署应以 GitHub Actions 通过记录为准。自有程序化模型由项目源代码生成；不采集未获授权的第三方 GLB。
