# V1.2｜50 个新增原创 Three.js 资产（435 → 485）

## 交付说明

本批共 **50 个独立可编辑源码模型、13 个分类、1,414 个具名 Mesh 几何部件**，单件至少 18 部件。所有模型具有中文及英文名称、稳定 ID、米制尺度、MIT 许可和独立 `src/models/*.js` 生成器。

适用于交互展示、网页/游戏场景搭建、学习原型；这些风格化低多边形模型不是具有医学、机械、安全性能的工业产品，不保证水密或可直接用于 3D 打印。

## 发布验收流程

```bash
python scripts/catalog.py validate
python scripts/catalog.py build
python -m unittest discover -s tests -v
npm install --no-audit --no-fund
node scripts/validate_models.mjs
npm run generate:assets
npm run verify:assets
python scripts/smoke_p2.py
npm run build
npm run test:gallery
npm run test:remote
```

验收输出目标：**485 WebP + 485 AVIF + 1,455 GLB（LOD0/LOD1/LOD2）**。构建和发布状态以 GitHub Actions 记录为准。
