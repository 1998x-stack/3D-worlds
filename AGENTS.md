# Agent instructions — 3D Worlds

This is a public, reusable **asset platform**, not a one-off scene demo.

## Invariants
- Canonical metadata lives in `catalog/models.json`. SQLite is generated by `python3 scripts/catalog.py build` and is **not** the source of truth.
- Stable `asset.id` never changes once published. Use a new version or slug for materially different geometry.
- All dimensions are in meters, Y-up, floor origin, and model-local center is x=z=0.
- Add an SPDX license identifier and provenance for every contributed asset; don't import third-party meshes without rights checks.
- Generators return `THREE.Group`, never mutate a global scene, and use explicit naming for important mesh parts.
- Static Pages must not assume server-side Python, live SQLite connections, or a remote MCP endpoint.
- MCP tools are read-only with respect to caller projects; do not execute arbitrary catalog-supplied code.
- Do not say a binary GLB exists in the repository unless its file has been committed. Browser-side export is different from a committed binary.
- Check model count and tests dynamically. Avoid code paths that enumerate all assets on the server or construct a WebGLRenderer for every result when scaling past the starter set.
- Model source copying must include `primitives.js` helpers; a bare generator with a relative import is not a portable snippet.

## Quality gate
1. `python3 scripts/catalog.py validate`
2. `python3 scripts/catalog.py build`
3. `python3 -m unittest discover -s tests -v`
4. `npm install && npm run build`
5. `npm run test:ingest` checks the official GLB validator + batch publication.
6. Open gallery; verify search, inspector controls, clipboard source, exported GLB and deep link.
7. Run MCP inspector with `python services/mcp_server.py` after `pip install -r requirements-mcp.txt`.

Read `docs/architecture.md`, `docs/threejs-research.md` and
`.codex/skills/threejs-model-builder/SKILL.md` for the workflow.
